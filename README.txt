WHAT THIS VERSION DOES
1. Keeps the existing Movie Wala design and automatic movie/series feeds.
2. Adds original Movie Wala guide/FAQ content to improve the site's useful content.
3. Adds additional ad-ready placements, but DOES NOT insert fake AdSense IDs.
4. Adds robots.txt and sitemap.xml.
5. Keeps the TMDB attribution notice.
6. Adds a clear non-piracy disclosure.

IMPORTANT ADSENSE STEP
Do not paste a made-up ca-pub ID. After Google AdSense gives you your actual publisher code,
paste Google's exact code in the <head> as instructed by AdSense. For display ad units,
use the exact ad-unit code/slot ID supplied by your AdSense account.

TMDB COMMERCIAL USE
The current site uses the TMDB API. TMDB states that a project whose primary purpose is
creating revenue for the owner is considered commercial and should use the commercial API/license.
Check TMDB's current commercial terms before monetizing.

GITHUB UPLOAD
Replace index.html with this version and upload robots.txt and sitemap.xml to the repository root.
Do not delete your existing about.html, contact.html, privacy.html, terms.html or disclaimer.html.

After committing:
1. Open the live site.
2. Hard refresh (Ctrl+F5).
3. Open /robots.txt and /sitemap.xml to confirm they load.
4. Submit the sitemap in Google Search Console.
5. Only after the site/content is ready, connect it to AdSense and paste Google's exact code.
